Endpoint-агенты (USB / прямая печать)

Endpoint-агент — служба на пользовательском ПК, учитывающая печать через USB/WSD/прямые IP-принтеры, которые НЕ проходят через Print Server. Токен показывается только один раз — при регистрации или ротации; в БД хранится только его хэш. Регистрация — ЛОКАЛЬНАЯ для этой площадки (не видна на центральном сервере напрямую — задания этих агентов попадают в центр как обычные print_jobs).
