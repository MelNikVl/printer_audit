Print Server / агенты

Статус вычисляется по возрасту heartbeat (не хранится как навсегда установленное значение): online ≤ 5 мин, warning ≤ 30 мин, иначе offline. Токен агента показывается только один раз — при регистрации или ротации; в БД хранится только его хэш.

«Последний контакт» — любой успешный запрос агента (batch или heartbeat). «Последняя синхронизация» — ТОЛЬКО когда последний присланный пакет был принят целиком, без единого отклонённого события; если часть пакета отклонена, эта метка не обновляется, а причина видна в «Ошибка приёма». «Ждёт отправки» — события, которые агент ещё повторит сам (сеть/не пришло подтверждение). «Отклонено» — события, которые центр явно счёл невалидными: автоматически они больше не повторяются, агенту нужен ручной agent_sync.py --retry-failed после исправления причины.
